顶层 platformio.ini 是唯一的构建编排点：指定 espressif32 @ ~6.5.0 + Arduino 框架、esp32-s3-devkitc-1 开发板、qio_opi 内存模式与 16MB flash；通过 partitions/custom_16MB_littlefs.csv 将 Flash 划分为 OTA/APP 与 LittleFS 数据区，使 data_assets 中的 Web 前端在运行时以文件系统形式被 firmware_core 读取；board_build.embed_files 将 compass_dial.png、woodfish.png 等静态图片直接编译进固件段，供应用层 UI 使用；libraries 目录作为本地库源被 PlatformIO 编译并链接到 firmware_core 生成的可执行文件。三个子模块之间无直接代码耦合，仅通过 LittleFS 文件系统路径与嵌入式资源两个边界交互。
