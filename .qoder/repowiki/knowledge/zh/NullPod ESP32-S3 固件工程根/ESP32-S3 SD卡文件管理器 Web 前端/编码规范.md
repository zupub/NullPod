- 所有对后端的请求统一使用 fetch() 或 XMLHttpRequest，并以 JSON 形式解析响应体，错误分支通过 showStatus(message, true) 展示失败提示。
- 文件操作（创建文件夹、删除、刷新列表、加载存储信息）在成功后统一调用 loadFileList(currentPath) 与 loadStorageInfo() 同步 UI。
- 用户反馈通过 showStatus() 动态插入 .status-message.success 或 .status-message.error 元素，并在 5 秒后自动移除。
- 文件大小与日期分别通过 formatFileSize(bytes) 与 formatDate(timestamp) 两个工具函数格式化后再渲染到页面。
