纯静态三件套（index.html + app.js + style.css），由 ESP32 的 HTTP 服务器直接作为静态资源返回，无构建步骤。
- index.html 定义双栏布局：左侧 sidebar（上传区、存储信息、新建文件夹）+ 右侧 main-content（工具栏、面包屑、文件列表）。
- app.js 在 DOMContentLoaded 后初始化，维护全局状态 currentPath、uploadQueue、currentUploadIndex、uploadStartTime；通过 XMLHttpRequest 调用后端 REST 风格接口：GET /list?path=、POST /upload（FormData）、GET /storage、POST /mkdir?path=、DELETE /delete?path=&isDirectory=、GET /download?path=。
- 上传采用串行队列模型：startUpload → uploadNextFile → uploadFile（XHR.upload.progress 回调驱动进度条与速度计算），完成后自动加载下一项并刷新文件列表与存储信息。
- style.css 使用 CSS Grid 渲染文件列表行，并通过 @media (max-width: 768px) 实现移动端单列适配。
