- 应用间状态切换采用「请求标志 + 主循环消费」模式：所有跨上下文信号定义为 `volatile bool g_request*`，并由 `App_RequestXxx()` 原子置位，`main.cpp` 的 `loop()` 逐轮检测并清零后切换 `AppState`。
- 菜单项以结构体数组 `menuItems[N]` 静态注册，每项包含 label、颜色、图标指针和 action 回调，新增功能通过在末尾追加条目即可扩展 Launcher 菜单。
- UI 绘制按区域拆分到独立的 `drawBackground`/`drawStatusBar`/`drawIconArea`/`drawLabelArea`/`drawHintBar` 方法，再由 `Draw()` 统一组合，便于按需增量重绘。
- RGB565 颜色统一通过 `rgb565(r,g,b)` 宏构造，并在需要变暗时走 `dim565(c, factor)` 路径，避免散落的位运算。
- 长耗时交互（如长按关机）使用 `millis()` 非阻塞计时配合状态机（`powerLongPressTriggered`/`powerHintShown`）推进 UI 进度条，而非 `delay` 独占。
